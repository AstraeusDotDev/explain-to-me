# Explain-to-Me 0.2.0 — Release preview

**Status:** Unreleased. Prepared for Tommy's review; repository remains private. No 0.2 tag, release, push or visibility change is authorized yet.

0.2 focuses on repeatable setup and a clearer source/CLI experience, not a new renderer or soundtrack workflow.

## Changes

- `--version` reads package metadata; help advertises the command.
- Doctor checks runtime/platform and explains missing prerequisites while distinguishing optional backends.
- More compact random private socket paths address the observed long-TMPDIR failure; paths that remain oversized are still refused and cleaned up.
- Apple/Kokoro duration failures retain measured attempts and explain script/target recovery.
- Clean-checkout test setup, Linux static CI and polished documentation.
- MIT license for project code, with separate third-party terms and security/contribution guidance.

See [CHANGELOG](../../CHANGELOG.md), [README](../../README.md) and [roadmap](../../ROADMAP.md).
