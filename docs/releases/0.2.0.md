# Explain-to-Me 0.2.0 — The tiny movie crew goes open source 🎬

**First open source release · 2026-10-15**

Turn local Markdown, plain text, or a reviewed manifest into a narrated, captioned explainer video. Version 0.2 makes setup clearer, gives agents a structured entry point, and brings the project into the open under the MIT license.

[Watch the getting-started movie](https://tommyallsup.github.io/explain-to-me/) or [download the MP4](https://github.com/TommyAllsup/explain-to-me/releases/download/v0.2.0/explain-to-me-v0.2.mp4). Bring a document. The tiny film crew will bring a whiteboard.

## What's here

- A rewritten [README](../../README.md) with real commands, examples, and a copy/paste agent installer prompt.
- A [private-workspace agent launcher](../agent-integration.md) with unique jobs, structured results, source/artifact provenance, and automated QC gates.
- Fixed prepared-manifest agent builds: the launcher omits document-only director flags and rejects explicit director, audience, or style options before creating a manifest job.
- Package-backed CLI `--version`, plus doctor checks for runtime/platform, required tools, and optional backends.
- Shorter private director socket paths for temporary roots that failed in 0.1. Oversized paths are still refused and cleaned up.
- Apple/Kokoro duration-failure messages with measured attempts and script/target recovery guidance.
- Clean-checkout test fixtures, Node 24 Linux static CI, contribution/security guidance, third-party notices, and an MIT project license.
- A goofy getting-started movie, website player, and downloadable release video.

Release checks pass: 18 TypeScript tests and 10 Python launcher tests, including regressions for prepared-manifest handling. See the [changelog](../../CHANGELOG.md) and [local verification evidence](../benchmarks/0.2-readiness.md) for details.

## Make your first video

Follow the [README quickstart](../../README.md#quickstart-roll-your-first-tiny-movie) for a prepared-manifest build with Apple speech, or give your agent the [installation prompt](../quick-install.md). Neither first-run path needs an LLM or Kokoro model.

## Scope and limitations

This is an early, macOS-first source release. The built-in renderer supports the technical-whiteboard theme at 720p/24 fps. The release movie's cartoons and imported music are bespoke production work, not built-in 0.2 options. No npm package, bundled application installer, PDF input, or Studio UI is included.

Automated checks don't establish factual correctness or human approval. Whole-process no-egress verification and broader acceptance work remain open. Dependencies, voices, models, and supplied media retain separate terms; the MIT project license doesn't establish complete commercial-use clearance. Read [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md) and [SECURITY.md](../../SECURITY.md).
