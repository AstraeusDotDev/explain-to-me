LESS SETUP SCROLLING. MORE MAKING.

Your first
“I made this.”

Use the bundled example and your Mac's Samantha voice. No separate language model or Kokoro setup needed.

Bring these along

  • macOS with the Samantha speech voice
  • Node.js 24+, npm, and Git
  • FFmpeg / ffprobe brew install ffmpeg

Run these commands from your terminal. Setup downloads dependencies and a rendering browser; builds use the installed tools.

Full setup & troubleshooting ↗
a small adventure in your terminal
# 1. Invite the little movie machine over
git clone --branch v0.2.0 https://github.com/TommyAllsup/explain-to-me.git
cd explain-to-me
npm exec --cache .cache/npm --yes --package=pnpm@10.18.3 -- pnpm install --frozen-lockfile

# 2. Download the rendering browser (one time)
node --input-type=module -e 'import {ensureBrowser} from "@remotion/renderer"; await ensureBrowser({chromeMode:"headless-shell"});'

# 3. Check the tools, then make a movie
npm exec --cache .cache/npm --offline --yes --package=pnpm@10.18.3 -- pnpm explain-to-me doctor
npm exec --cache .cache/npm --offline --yes --package=pnpm@10.18.3 -- pnpm explain-to-me build \
  --manifest fixtures/golden-manifests/whisper-vs-tts.json \
  --tts apple --voice Samantha --duration 60s \
  --output out/my-first-explainer

open out/my-first-explainer/video.mp4
