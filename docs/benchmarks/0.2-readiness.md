### Socket compatibility finding and fix

The initial prepared short-name fix allocated a bare `s` basename. A real model build failed startup because the installed llama-server recognizes Unix host paths only when they end in `.sock`, as documented by its own `--help`.

The final allocator uses a random private `d-` directory and `s.sock`, retains the 100-byte guard and owned cleanup, and has a suffix regression assertion. The assertion failed before the correction. A successful real build exercised a temporary root where the old candidate path was 103 bytes and the new one was 94 bytes. An oversized root is still refused without deleting an unrelated marker file. No TCP fallback or global temporary-directory change was introduced.

## Release audit verification

On 2026-10-15, TypeScript checking (including the release-video source), all 18 TypeScript tests and all 10 Python agent-launcher tests passed on Node.js 25.8.1. No dependency changes were required. This local rerun does not replace a remote CI result.

The job retained source identity, structured results and hashes for all six required artifacts. Human review remained pending and whole-process egress remained unverified.

This snapshot reused the host's installed dependencies, rendering browser and Samantha voice. It verifies the corrected launcher path without concurrent source edits; it is not a second clean installation or separate-machine certification.

## Launch movie evidence

The separate getting-started production uses the project's narration/timeline/caption modules, a custom Remotion cartoon composition, and the owner's supplied “Business As Usual” soundtrack. Reproduction source is in `scripts/release-video/`; the website assets include `production.json` with media hashes and soundtrack provenance. The original music recording is not included separately.

The final showcase has 3,319 frames at 24 fps (138.291667 s), 1280 × 720 H.264 video, and 48 kHz stereo AAC audio; its size is 8,353,814 bytes. A full decoder pass completed without errors. The soundtrack measured −16.8 LUFS integrated loudness and −4.6 dBFS true peak. Eight scene stills were inspected with no observed clipping. These signal and sampled-layout checks do not establish full human watch/listen approval, nor do they add cartoon or music options to the normal CLI.
