## Scope and safety

- Canonical checkout: ~/Development/github/TommyAllsup/explain-to-me. GitHub owner/account: TommyAllsup; repository initially private. Preserve dirty work and history; no force push or history rewrite.
- v0.1.0 is an initial source/CLI release with the implemented preview profile, document/prepared-manifest inputs, local/template direction, local narration, pronunciation maps, deterministic scenes, measured captions, caching and automated validation. It is not an npm package publication or a full-MVP/commercial-readiness assertion.
- Client research, production videos/scripts, listening exports, source music, generated outputs, model assets, private local experiments, environments and credentials are excluded. Use only generic synthetic fixtures in docs, CI and source-only agent staging.
- Cartoon styling, imported music, per-chunk fixed rates, listening feedback and ASR/MOS remain demonstrated external workflows, not advertised built-in v0.1 CLI flags. Generalizing them is the next milestone.
- Keep code unlicensed/private (package license UNLICENSED) until the owner selects a distribution license; do not silently grant rights. Model/renderer commercial review, whole-process egress proof and broad full-MVP acceptance remain explicit open gates.
